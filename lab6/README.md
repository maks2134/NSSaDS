# Лабораторная работа №6: UDP P2P чат (broadcast + multicast)

Одноранговый UDP-чат на Go. Каждый процесс одновременно отправляет и принимает сообщения. Поддерживаются широковещательный и многоадресный режимы с переключением во время работы.

## Требования

- Go 1.26+
- Два и более физических хоста в одной L2-сети (для сдачи)
- Windows или Linux/macOS/BSD

## Сборка

```bash
make deps
make test
make build
make build-all   # linux/darwin/windows
```

## Запуск

```bash
./bin/lab6
./bin/lab6 -port 9000 -nick alice -iface en0
./bin/lab6 -group 239.255.42.42
```

При старте программа автоматически определяет сетевой интерфейс и выводит:

- имя интерфейса
- IPv4-адрес
- маску подсети
- broadcast-адрес
- текущий режим (`broadcast` по умолчанию)

## Команды чата

| Команда | Описание |
|---------|----------|
| `/net` | Показать сетевые параметры и режим |
| `/peers` | Список IP запущенных приложений в текущем режиме |
| `/mode broadcast` | Переключиться на broadcast |
| `/mode multicast` | Переключиться на multicast (join группы) |
| `/leave` | Выйти из multicast-группы, перейти в broadcast |
| `/join` | Войти в multicast-группу |
| `/ignore <ip>` | Игнорировать хост локально и уведомить остальных |
| `/unignore <ip>` | Снять игнор |
| `/help` | Справка |
| `/quit` | Отправить BYE и завершить работу |

Любой другой текст отправляется как сообщение чата.

## Протокол

- Один UDP-датаграмм = одно сообщение
- Заголовок 12 байт + payload (magic `NS6\x01`, type, mode, node id, length)
- Типы: HELLO, BYE, CHAT, IGNORE, UNIGNORE
- HELLO каждые 2 с для discovery; пир удаляется через 8 с без HELLO
- Discovery и чат работают только в текущем режиме

## Сценарий сдачи

1. Запустить `./bin/lab6` на двух машинах в одной подсети.
2. Проверить `/net` — корректные IP, маска, broadcast.
3. Обменяться сообщениями в режиме broadcast, выполнить `/peers`.
4. Переключить обе машины: `/mode multicast`, снова обменяться сообщениями.
5. На одной машине `/leave`, убедиться что она в broadcast, вторая остаётся в multicast.
6. `/ignore <ip>` — сообщения игнорируемого хоста не показываются у всех участников.
7. Подключить третью машину без перезапуска уже работающих процессов.

## Архитектура

```
lab6/
├── cmd/lab6/                 # CLI entry point
├── internal/domain/          # сообщения, пиры, интерфейсы
├── internal/infrastructure/
│   ├── netiface/             # автоопределение IP/маски/broadcast
│   └── udp/                  # сокет, multicast, sockopt_* 
├── internal/usecase/         # чат, команды, run loop
└── pkg/config/               # константы и конфигурация
```

Платформенные socket options спрятаны в `sockopt_unix.go` / `sockopt_windows.go`. Бизнес-логика общая.

## Замечания

- Чтение/запись пакетами до 64 KiB, не по одному байту
- Процесс не завершается при отключении других участников
- Выход только по `/quit` или Ctrl+C (с отправкой BYE)
